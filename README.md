# Interesting things to know about these backups

- About 90% backups: In CGBJ build, now you can execute the game in lowest end computers! 

Just edit the cmd executable "Play-VIctory-4GB.cmd".

```bat
if not defined VICTORY_GAME_DIR set "VICTORY_GAME_DIR=C:\ImNotRockstarPleaseDontStrikeOnMe\Xbox\GTAVI-DIRECTORY"
```

Change the value **VICTORY_GAME_DIR** to your retail Xbox copy directory. 

Example: **"C:\dumped-xbox-series\Grand Theft Auto VI"**

```bat
if not defined VICTORY_GAME_DIR set "VICTORY_GAME_DIR=C:\dumped-xbox-series\Grand Theft Auto VI"
```

- In VIctory Lite from vix0e0e, supports lowest end computers with light fix in areas that previously depended on dynamic light sources from the engine, like the first spawn in Prison requires and more specific areas related to rooms.

Execute any of these cmd executables: **Play-VIctory.cmd** and **Play-4GB-VRAM.cmd**
